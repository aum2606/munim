# Pilot onboarding checklist

## Operator, before the owner session

- [ ] Deploy a reviewed revision and apply migrations; verify public HTTPS and private DB/Redis.
- [ ] Run offline checks and an opt-in real-model evaluation in a dedicated database.
- [ ] Verify encrypted object-store backup, isolated restore and alert failure/recovery delivery.
- [ ] Document provider handling, privacy contact, retention and deletion responsibilities.
- [ ] Configure a Meta test number/recipient and complete the live WhatsApp acceptance flow.
- [ ] Prepare the business's catalogue CSV/XLSX, FAQs, GST details and opening hours.

## Owner, target under 30 minutes

- [ ] **0–5 min:** Sign in, open **Setup**, enter business address, phone, state and GSTIN where applicable.
- [ ] **5–15 min:** Import prices from CSV/XLSX, review mapped columns/paise values, upload FAQs/policies and wait for ingestion to finish.
- [ ] **15–20 min:** Save business category, tone, languages and opening hours.
- [ ] **20–25 min:** Start a playground conversation. Ask a known catalogue question, check its citation, and try an unsupported question and a human request.
- [ ] **25–30 min:** Confirm tax settings, copy the widget snippet into the business website and test its consent notice. Finish Setup; connect WhatsApp using the separate owner channel settings when ready.
- [ ] Record actual elapsed time and any intervention; a fast scripted browser run does not establish every owner's onboarding time.

## First week

- [ ] Review pending quotes and follow-up drafts daily; confirm prices against the catalogue.
- [ ] Exercise take-over/assist/return-to-AI with a colleague and verify staff permissions.
- [ ] Resolve top knowledge gaps; review Overview, Ask Munim and Monday's digest.
- [ ] Practice a synthetic customer's erasure and retryable file cleanup.
- [ ] Track §15 pilot metrics against the owner's baseline and record time saved.
- [ ] Keep real-model, live-channel and deployment gates explicitly pending until evidenced.
